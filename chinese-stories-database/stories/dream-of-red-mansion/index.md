# 🏮 红楼梦故事集

## 系列说明

《红楼梦》不只有宝黛钗的爱情，还有大观园里少年们的诗意生活。我们选取温暖、有趣、富有成长意味的片段，带孩子们走进这座古典文学的花园。

## 阅读建议

1. **感受美**：带孩子品味故事里的花园、诗词、服饰之美
2. **找自己**：问问孩子觉得自己最像大观园里的谁
3. **写日记**：像香菱一样，用一两句话记下每天的趣事
4. **春天行动**：学宝玉放风筝，或学湘云在花下读一本书
