# 🀄️ 成语故事集

## 系列说明

每一个成语背后，都藏着一个生动的小故事。通过这些故事，孩子们可以轻松理解成语的含义，学会做人做事的道理，感受汉语言的智慧。本系列涵盖春秋战国典故、秦汉历史、三国故事、唐宋传奇等，从先秦到明清，一应俱全。

## 阅读建议

1. **先猜后读**：先让孩子根据成语猜意思，再读故事验证，增加期待感
2. **情景表演**：把成语故事演出来，印象更深刻。可参考故事中的“互动思考”设计表演环节
3. **举一反三**：引导孩子说说生活中可以怎样用这个成语，每天学一个成语并尝试使用
4. **画成语**：画出故事中最精彩的一幕，配上一句成语。故事中的“AI绘图提示词”可作参考
5. **按龄选读**：低龄儿童（5-7岁）建议从🟢简单难度的短篇开始；高龄儿童（8-11岁）可挑战🟡中等难度的长篇故事
6. **主题阅读**：可按主题串联阅读，如连续阅读“勤奋与坚持”系列，培养学习好习惯；或阅读“勇气与决断”系列，感受英雄气概
7. **朝代之旅**：按朝代顺序阅读，了解成语产生的历史背景，同步学习中国历史
